새봄 문서 비교 · EXE + 로컬 웹 UI

EXE 실행 (권장)

dist/SaebomCompare.exe를 더블클릭하면 기본 브라우저에서 http://127.0.0.1:18765/ 화면이 열립니다. Python 설치 없이 사용할 수 있습니다.

  1. 최신 목록 가져오기로 현재 사이트의 메일·계약 목록을 저장합니다. 이 단계에는 인터넷이 필요합니다.
  2. 검색 후 체크박스로 비교할 메일을 한 건 이상 선택합니다.
  3. 선택 자료 저장으로 선택 메일의 PDF와 지출 계약서 PDF를 저장합니다. 다시 실행하면 원본을 갱신합니다. 인터넷이 필요합니다.
  4. 선택 메일 로컬 비교는 저장한 자료만 사용합니다. 인터넷과 AI를 사용하지 않습니다.
  5. 메일을 클릭하면 본문, 항목별 근거와 원본 PDF 두 개가 표시됩니다. CSV 보고서도 저장할 수 있습니다.

목록에는 세금계산서와 해당 계약서의 저장 상태가 각각 표시됩니다. PDF 저장 전에는 메일 정보로 계약을 잠정 연결하고, 저장 후에는 PDF 사업자번호로 연결합니다. 연결 후보가 없거나 여러 개이면 저장 여부를 확정하지 않습니다. 저장됨은 비교 결과의 일치를 뜻하지 않습니다.

  1. 프로그램 종료를 누르면 서버가 종료됩니다. 브라우저 탭만 닫으면 서버는 유지됩니다.

오프라인에서는 마지막으로 저장한 목록/PDF를 사용합니다. 목록의 조회 시각과 파일 저장 여부가 화면에 표시됩니다. 사이트 자료가 없을 때도 로컬 PDF 직접 비교에서 두 파일을 선택할 수 있습니다. OCR은 지원하지 않습니다.

EXE 실행 시 자료는 %LOCALAPPDATA%\SaebomCompare에 저장됩니다. 실행 파일을 교체해도 자료가 유지됩니다. 실제 경로는 UI 하단에 표시됩니다. downloads에 원본/추출 텍스트/목록, reports에 비교 이력/CSV/JSON, app.log에 실행 로그를 저장합니다.

build.cmd로 단일 EXE를 다시 만들 수 있습니다. 외부 AI API와 CDN을 사용하지 않습니다. 현재 사이트의 공개 양식 전용이며, 로그인과 임의 양식의 의미 해석은 별도 개발이 필요합니다.

소스 실행

기본 실행은 실행.cmd 또는 py web_app.py입니다. 아래 Tkinter 안내는 이전 UI용 app.py 실행 방식입니다.

Windows에서 실행.cmd를 더블클릭하세요. Python 3.10 이상과 pypdf가 필요합니다. 처음 설치하는 PC는 설치.cmd를 먼저 실행하세요.

  1. 메일 목록이 최신순으로 표시됩니다. 확장 케이스 설정을 바꾼 뒤에는 새로고침하세요.
  2. 메일을 선택하고 선택 메일 비교 또는 전체 PDF 메일 비교를 누릅니다.
  3. 각 항목의 일치/불일치/확인 필요와 근거 금액을 확인합니다.
  4. 원본 PDF 열기 버튼으로 직접 확인합니다. 결과는 reports의 CSV/JSON, 원본과 추출 텍스트는 downloads에 저장됩니다.

다운로드 후 PDF 텍스트 분석과 비교는 로컬에서 수행합니다. 외부 AI 서비스와 브라우저 확장은 사용하지 않습니다. 목록 조회 및 원본 다운로드에는 인터넷이 필요합니다. 현재 https://sbgw.vercel.app/의 공개 데이터 구조 전용입니다. 로그인 사이트와 일반 메일 서비스는 별도 어댑터가 필요합니다.

비교 기준

  • 세금계산서 PDF의 공급자 사업자번호로 지출 계약 후보를 찾고 계약 PDF에서도 번호를 확인합니다.
  • PDF 공급가액+세액=합계, 메일 본문에 명시된 청구 합계와 PDF 합계를 별도 비교합니다.
  • PDF 계약 조항의 월 금액과 부가세 포함/별도를 반영한 예상 합계를 대조합니다.
  • 청구 대상 월 전체가 계약기간에 포함되는지 확인합니다.
  • 분할 청구는 금액이 일치해도 공급/검수 조건 이행을 자동 판단할 수 없으므로 확인 필요로 남깁니다.
  • 계약 후보 복수, 텍스트 추출 실패, 스캔 PDF, 알 수 없는 양식은 자동 일치 처리하지 않습니다. OCR은 포함하지 않습니다.
  • 양식 기반 규칙 추출이므로 최종 판단은 원본과 함께 검토하세요. 이 앱은 기안을 상신하지 않습니다.
