4. 비교 항목 코드값

compare_mail()이 만드는 항목 판정 값: 일치 / 불일치 / 확인 필요. 최종 우선순위는 불일치 → 확인 필요 → 일치. 위치 표시는 계산서 합계, 메일과 PDF 합계, 사업자번호, 월 계약금액, 계약금액, 분할 지급, 분할 금액 항목만 지원한다(TB-04).

5. 한계

  • 글자가 있는 PDF만 읽는다. 스캔 PDF는 OCR이 없어 확인 필요로 남는다(read_pdf()).
  • 현재 새봄 양식 문구에 맞춘 정규식이다(parse_invoice(), parse_contract()).
  • 같은 값이 여러 곳에 있으면 모두 표시하며, 부분 문자열도 일치할 수 있다(find_boxes()).
