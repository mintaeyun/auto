비교값 위치 표시 화면 (금액·사업자번호 우선)

Context

세금계산서·계약서 비교 결과(D:\chaai\07_auto)에서 각 비교값이 두 PDF의 어느 부분에 있는지 보여 주는 화면을 추가한다. 사용자 선택: PDF 위 형광 박스 방식, 금액·사업자번호 항목만 먼저. 결과물은 v2 EXE에 포함.

이미 끝난 부분 (플랜모드 진입 전에 작성)

  • locate.py 신규: find_boxes(path, values)는 pypdfium2로 값이 나온 페이지와 위치(페이지 대비 비율 좌표)를 반환하고, render_page(path, n)는 PNG를 만든다. 샘플 PDF로 동작 확인.
  • compare_core.py: attach_locations(result) 추가, compare_mail 끝에서 호출. 항목(계산서 합계, 메일과 PDF 합계, 사업자번호, 월 계약금액, 계약금액, 분할 지급/금액)마다 where: {invoice: [...], contract: [...]} 저장.
  • requirements.txt에 pypdfium2>=5,<6 추가. 기존 단위 테스트 14개 통과.

남은 작업

  1. web_app.py: GET /api/page?path=&page= 추가. /files와 같은 허용 폴더 검사(data_roots())를 적용하고, render_page PNG와 전체 페이지 수를 반환.
  2. web/index.html:
  3. "비교값 위치 확인" 패널 신규: 좌측 세금계산서, 우측 계약서 페이지 이미지 위에 절대 위치 박스를 겹쳐 표시.
  4. 결과 항목(ul.checks > li)을 클릭하면 해당 항목의 where 박스를 두 이미지에 표시하고 해당 페이지로 이동. 일치는 초록, 불일치는 빨강, 확인 필요는 주황.
  5. where가 비었거나 스캔 PDF면 "위치 확인 불가"로 표시. 페이지 이전/다음 버튼.
  6. 기존 showResult를 감싸서 확장(기존 코드 최소 변경), 외부 CDN 없음.
  7. 테스트 추가: tests/test_locate.py에서 find_boxes가 샘플 PDF에서 값 위치를 찾는지, 없는 값은 빈 목록인지 확인.
  8. build.cmd에 pypdfium2 포함 확인 후 SaebomCompare_v2.exe 재빌드(필요 시 --collect-all pypdfium2).

검증

  • python -m unittest discover -s tests
  • 소스 서버를 임시 포트로 실행해 /api/compare 결과에 where가 들어 있고 /api/page가 PNG를 반환하는지 확인
  • v2 EXE를 실행해 같은 API 확인(브라우저 화면의 박스 위치는 사용자 눈으로 최종 확인 필요)

참고

  • 스캔 PDF(OCR 없음)는 위치를 찾지 못하는 것이 정상 동작이다.
