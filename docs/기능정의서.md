# 기능정의서

계산서×계약서 비교 프로그램(로컬 웹 UI)의 기능·화면·API 정의서. 이 문서가 원본이며 HTML은 `build_docs.cmd`로 생성한다.
ID 규칙: 기능 `FN-nn`, 화면 `SC-nn`, API `API-nn`, 데이터 `TB-nn`. 코드는 `` `함수명()` `` 또는 `` `파일.py:줄` `` 로 적는다.

## 1. 화면

### SC-01 받은 메일함
메일 목록, 검색, 체크박스 선택, 저장 상태 표시, 비교 결과 요약(`web/index.html`의 `render()`). 데이터는 TB-01, TB-03을 사용한다.

### SC-02 비교값 위치 확인
비교 항목을 클릭하면 두 PDF 페이지 위에 형광 박스를 겹쳐 표시한다(`drawLoc()`, `pickCheck()`). 데이터는 TB-04를 사용한다.

### SC-03 원본 PDF 확인
세금계산서·계약서 원본을 iframe으로 표시한다(`showResult()`). 파일은 API-07로 받는다.

### SC-04 로컬 PDF 직접 비교
사이트 목록 없이 PDF 두 개를 올려 비교한다. 결과는 SC-01의 비교 근거 영역에 표시한다.

## 3. API 정의

모든 POST는 헤더 `X-App-Token`이 필요하다(`Handler.do_POST()`). 서버는 `127.0.0.1:18765`에서만 응답한다(`main()`).

| API ID | 메서드·경로 | 설명 | 사용 기능 |
|--------|------------|------|-----------|
| API-01 | POST /api/sync | 사이트 목록을 받아 TB-01에 저장 | FN-01 |
| API-02 | GET /api/catalog | 저장된 목록과 저장 상태 반환 | FN-02 |
| API-03 | POST /api/prepare | 선택 메일과 계약 PDF 저장 | FN-03 |
| API-04 | POST /api/compare | 선택 메일 비교 후 결과·좌표 반환 | FN-04 |
| API-05 | POST /api/local-compare | 업로드한 PDF 두 개 비교 | FN-05 |
| API-06 | GET /api/page | PDF 한 페이지를 PNG로 반환 (`info=1`이면 전체 쪽수) | FN-06 |
| API-07 | GET /files | 허용된 데이터 폴더 안의 PDF 등 반환 | FN-07 |
| API-08 | GET /api/history | 누적 비교 이력 반환 | FN-08 |
| API-09 | GET /api/jobs/{id} | 백그라운드 작업 상태 조회 | FN-09 |
| API-10 | POST /api/shutdown | 서버 종료 | FN-09 |

## 4. 비교 항목 코드값

`compare_mail()`이 만드는 항목 판정 값: `일치` / `불일치` / `확인 필요`. 최종 우선순위는 불일치 → 확인 필요 → 일치.
위치 표시는 `계산서 합계`, `메일과 PDF 합계`, `사업자번호`, `월 계약금액`, `계약금액`, `분할 지급`, `분할 금액` 항목만 지원한다(TB-04).

## 5. 한계

- 글자가 있는 PDF만 읽는다. 스캔 PDF는 OCR이 없어 `확인 필요`로 남는다(`read_pdf()`).
- 현재 새봄 양식 문구에 맞춘 정규식이다(`parse_invoice()`, `parse_contract()`).
- 같은 값이 여러 곳에 있으면 모두 표시하며, 부분 문자열도 일치할 수 있다(`find_boxes()`).
