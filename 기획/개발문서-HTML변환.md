# 개발문서 Standalone HTML 변환 + 추적표·코드 색인

## Context
`D:\chaai\07_auto`(계산서×계약서 비교 프로그램)에는 README.md와 `기획\*.md`만 있고 기능정의서·테이블명세서·ERD·시퀀스 문서가 없다. 사용자 결정: 이 폴더 문서 + 코드로 새로 작성하고, Mermaid 다이어그램을 오프라인 내장 HTML로 변환한다. md가 원본이고 HTML은 스크립트로 재생성한다. 루트 `Todo.md`는 작성 완료(사용자가 체크).

## 산출물 구조
- `docs\` (신규 md 원본, 사용자가 이후 수정)
  - `기능정의서.md` — 기능 ID `FN-nn`, 화면 ID `SC-…`, API ID `API-…`, 각 항목의 연결(화면→API→함수→데이터)
  - `데이터명세서.md` — 이 앱은 DB가 없으므로 데이터 구조(catalog JSON, results.json/csv, 추출 txt, `where` 박스 구조)를 `TB-…` 테이블/컬럼로 정의
  - `다이어그램.md` — Mermaid: ERD(데이터 관계), 클래스/모듈 의존, 시퀀스(비교 요청→PDF 읽기→위치 찾기→화면)
  - 기존 `README.md`, `기획\*.md`는 수정하지 않고 그대로 변환 대상에 포함
- `tools\build_docs.py` — 변환 스크립트 (표준 라이브러리 + 필요 시 `markdown` 대신 자체 경량 변환기; 외부 설치 최소화)
- `build_docs.cmd` — 더블클릭 재실행
- `html\` (생성물, 자동 덮어쓰기): 문서별 HTML + `추적표.html` + `코드색인.html` + 공용 인라인 CSS/JS. 외부 CDN 없음
- `vendor\mermaid.min.js` — 오프라인 내장용. 받아서 인라인한다(다운로드는 실행 시 사용자 승인 후, 버전 고정).

## 동작 설계
1. **ID 사전 구축**: md 헤딩/표의 `FN-…`, `SC-…`, `API-…`, `TB-…`, `TB-….컬럼`, 코드값(예: 상태 코드)을 정의 위치로 등록.
2. **코드 색인**: `ast`로 `*.py`의 클래스/함수/줄번호 추출, `web\index.html`은 정규식으로 JS 함수 추출. `파일:줄` 표기(`compare_core.py:120`)와 `` `함수명()` `` 표기를 심볼로 인식.
3. **자동 링크**: 본문 텍스트(코드스팬 포함)에서 ID·테이블.컬럼·심볼·`파일:줄`을 찾아 정의 위치로 링크. 모호하면(동명 심볼) 링크하지 않고 미해결 보고에 기록.
4. **백링크**: 정의 항목마다 "참조하는 곳" 목록(문서·섹션 링크)을 생성해 하단에 표시.
5. **다이어그램 클릭 이동**: Mermaid 노드 텍스트를 사전과 매칭해 `click` 대신 렌더 후 DOM 노드에 핸들러를 달아 테이블 정의 또는 코드 색인 위치로 이동.
6. **추적표.html**: 기능ID → 화면 → API → 함수(파일:줄) → 데이터(TB) 행 단위 표, 각 셀 링크, 비어 있는 연결은 경고 표시.
7. **코드색인.html**: 파일별 클래스/함수/줄번호, 호출·참조하는 문서 백링크.
8. **재실행**: `build_docs.cmd`가 md 변경 시 전체 재생성(소규모라 증분 불필요), 끝에 링크 끊김·미해결 ID 요약 출력. md는 읽기만 한다.
9. 소스 주석은 memory.md의 기능명세 규칙(파일 상단 목적, 함수별 역할/입력/출력/부작용, 한계)을 따른다.

## 재사용
- 코드 구조 근거: `compare_core.py`, `locate.py`, `web_app.py`(엔드포인트 `/api/catalog, /api/compare, /api/page, /files, /api/local-compare, /api/shutdown`), `web\index.html`
- 기존 문서 `기획\*.md`의 용어를 기능 ID 설명에 재사용

## 단계
1. `docs\*.md` 초안 작성 (코드에서 사실 확인 후 작성, 추측은 "추정" 표기)
2. `tools\build_docs.py` 구현 (ID 사전 → 코드 색인 → 링크/백링크 → 페이지 출력)
3. Mermaid 내장 및 노드 클릭 이동
4. 추적표·코드 색인 페이지
5. `tests\test_build_docs.py` (링크 해석, 백링크, 미해결 보고) 및 `build_docs.cmd`
6. `Todo.md` 진행 상황 메모만 갱신(체크는 사용자)
